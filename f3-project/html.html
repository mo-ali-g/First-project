أهم وسوم (Tags) لغة HTML5

1. الهيكل الأساسي للصفحة

  • <!DOCTYPE html> : تعريف نوع المستند كـ HTML5.
  • <html> : الوسم الجذري الذي يحتوي على كل الصفحة.
  • <head> : يحتوي على إعدادات الصفحة والعنوان والروابط.
  • <title> : عنوان الصفحة الذي يظهر في تبويب المتصفح.
  • <body> : يحتوي على كل المحتوى المرئي للمستخدم.
  • <meta> : لتحديد الترميز ووصف الصفحة لمحركات البحث.

2. النصوص والعناوين

  • <h1> - <h6> : العناوين من الأكبر للأصغر.
  • <p> : فقرة نصية عادية.
  • <strong> : نص عريض (Bold) ذو أهمية.
  • <em> : نص مائل (Italic) للتأكيد.
  • <mark> : تظليل النص باللون الأصفر.
  • <br> : النزول إلى سطر جديد.
  • <hr> : رسم خط أفقي فاصل.
  • <span> : تحديد جزء صغير من النص لتنسيقه.

3. الروابط والوسائط

  • <a> : رابط تشعبي للانتقال لصفحة أخرى.
  • <img> : إدراج صورة.
  • <video> : تشغيل ملف فيديو.
  • <audio> : تشغيل ملف صوتي.
  • <iframe> : تضمين صفحة ويب أو فيديو يوتيوب.

4. القوائم والجداول

  • <ul> : قائمة غير مرتبة (نقطية).
  • <ol> : قائمة مرتبة (مرقمة).
  • <li> : عنصر داخل القائمة.
  • <table> : إنشاء جدول.
  • <tr> : صف داخل الجدول.
  • <th> : خلية عنوان في الجدول.
  • <td> : خلية بيانات في الجدول.

5. النماذج (Forms) والإدخال

  • <form> : حاوية لجمع بيانات المستخدم.
  • <input> : حقل إدخال (نص، كلمة مرور، إيميل، إلخ).
  • <textarea> : مربع نص كبير للرسائل الطويلة.
  • <button> : زر قابل للضغط.
  • <select> : قائمة منسدلة للاختيار.
  • <option> : خيار داخل القائمة المنسدلة.
  • <label> : عنوان توضيحي لحقل الإدخال.

6. وسوم التقسيم الدلالية (Semantic HTML5)

  • <div> : حاوية عامة لتقسيم العناصر.
  • <header> : رأس الصفحة أو القسم.
  • <nav> : شريط التنقل والقوائم الرئيسية.
  • <main> : المحتوى الرئيسي للصفحة.
  • <section> : قسم مستقل داخل الصفحة.
  • <article> : مقال أو محتوى منفصل.
  • <aside> : شريط جانبي.
  • <footer> : تذييل الصفحة (أسفل الموقع).
