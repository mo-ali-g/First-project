أهم خصائص (Properties) لغة CSS

الألوان والخلفيات (Colors & Backgrounds)

  • color: white; : تغيير لون النص والكتابة.
  • background-color: black; : تغيير لون خلفية العنصر أو الصفحة.
  • background-image: url("bg.jpg"); : وضع صورة كخلفية للعنصر.
  • background-size: cover; : جعل صورة الخلفية تغطي المساحة بالكامل.
  • opacity: 0.8; : التحكم في درجة شفافية العنصر (من 0 إلى 1).

تنسيق النصوص والخطوط (Text & Fonts)

  • font-size: 20px; : تحديد حجم الخط.
  • font-family: Arial, sans-serif; : اختيار نوع الخط.
  • font-weight: bold; : جعل الخط عريضاً وسميكاً.
  • text-align: center; : محاذاة النص في المنتصف (أو right و left).
  • text-decoration: none; : إزالة الخط السفلي من الروابط.

الصناديق والحدود والمسافات (Box Model)

  • width / height : تحديد عرض وارتفاع العنصر.
  • padding: 15px; : المسافة الداخلية بين المحتوى وإطار الصندوق.
  • margin: 20px; : المسافة الخارجية بين الصندوق والعناصر المجاورة.
  • border: 2px solid blue; : رسم إطار ملون حول العنصر.
  • border-radius: 12px; : جعل زوايا الصندوق دائرية وناعمة.

ترتيب وتوزيع العناصر (Layout & Flexbox)

  • display: flex; : تفعيل الصندوق المرن لترتيب العناصر بجانب بعضها.
  • justify-content: center; : محاذاة العناصر أفقياً في المنتصف.
  • align-items: center; : محاذاة العناصر عمودياً في المنتصف.
  • display: grid; : تقسيم العناصر إلى شبكة من الصفوف والأعمدة.
  • gap: 10px; : ترك مسافة متساوية بين العناصر المتجاورة.
